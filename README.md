# 💼 Employee Salary Estimation Engine

An end-to-end Machine Learning web application designed to estimate fair market annual salary based on candidate experience, education level, age, gender, and job function.

---

## 🛠️ Tech Stack
- **Language:** Python 3.11+
- **Data Manipulation & Preprocessing:** Pandas, NumPy
- **Machine Learning:** Scikit-learn (Linear Regression, Decision Tree, Random Forest)
- **Model Persistence:** Joblib
- **Frontend / Web UI:** Streamlit

---

## 📊 Features & Input Variables
- `YearsExperience`: Total years of professional industry experience
- `Age`: Candidate age
- `Gender`: Female / Male demographic indicators
- `EducationLevel`: Bachelor's, Master's, PhD, High School
- `JobTitle`: Role function (e.g., Software Engineer, Data Scientist, Product Manager)
